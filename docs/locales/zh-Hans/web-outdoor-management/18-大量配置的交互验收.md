# 大量配置的交互设计与验收

本文补充 02 的交互要求。以下为交付标准，不代表已全部实现或通过实机验收。配置覆盖率与交互完成度分别核对，不能以字段可读写代替表单可用性。

## 导航与信息层级

沿用现有 Pages 的主题、导航、卡片和按钮。桌面使用分类侧栏与右侧表单，窄屏使用分类选择和单列卡片。连接状态、设备名称、身份指纹摘要及未保存修改数持续可见。

现有九个一级分类继续作为入口：设备与身份、无线与协议、Reticulum、频道与消息、GPS 与定位、轨迹与地图、显示与交互、网络与外设、其他设置。分类下按任务拆卡片，例如定位分为基本定位、启动与接收、运动与省电、外部 NMEA 输出；Reticulum 分为接口、投递与传播、群组引用。独立身份备份与恢复不混入普通参数表。

“其他设置”是待分类字段的兜底入口，发布前逐项检查其内容，不能长期把大量已知配置放在这里。分类同时显示修改数和错误数；常用设置先展示，高级参数可折叠，但搜索必须能找到折叠区内的字段。

全局搜索覆盖名称、说明与技术键，不检索密码内容。结果显示所属分类、字段名称和当前值摘要；点击直接定位、展开并聚焦字段。提供“仅看已修改”和“仅看错误”。从搜索返回分类不丢失输入。

## 字段呈现与录入

每个可编辑字段需要名称、当前值、必要的简短解释、单位、有效范围或选项。默认值必须有可核对的固件来源，不能猜测。技术键放在次要详情中；帮助首先说明改变该值对用户的实际影响。

| 数据 | 首选交互 | 必须保留的边界 |
|---|---|---|
| 布尔开关 | 开关或复选框，旁边解释启用效果 | 禁用功能时保留其参数，除非用户明确删除 |
| 枚举 | 具名下拉或少量单选项 | 未知旧值可见并保留，不静默替换 |
| 时间、距离、频率 | 带单位数值输入或真实支持的预设 | 展示单位换算；特殊哨兵值使用语义名称 |
| 亮度、音量 | 滑块配数值输入 | 键盘可精确输入，范围来自实际能力 |
| 位掩码 | 具名多选项配高级原始值 | 未识别位保留，不因编辑已知位而丢失 |
| 地址、端口 | 分开的输入框，提供格式示例 | 不把完整 URL 当作主机名；错误留在原输入旁 |
| 密码、网络密钥 | 默认隐藏，可显式显示、替换或清空 | 区分未改、空值和删除；搜索及修改预览不泄漏内容 |
| 身份哈希 | 格式提示、粘贴、校验、复制 | 说明字节数及编码，不与设备私钥混淆 |
| Wi-Fi、接口、频道等集合 | 有标题的重复卡片，支持增删及启停 | 最大容量、稳定标识、重复校验；折叠摘要不显示秘密 |
| 派生信息 | 带原因的只读值 | 不显示成可保存的普通输入框 |

例如屏幕超时 300000 在当前固件表示“保持常亮”，不能显示成“五分钟”；GNSS 掩码使用卫星系统多选，NMEA 语句方案使用具名枚举。不能仅按底层整数类型生成统一数字框。

## 依赖、能力与保存

依赖字段显示在同一卡片内。选项变化时说明哪些参数生效、暂不生效或被硬件限制；暂不生效的值保留。依赖规则逐项以固件代码或协议定义为依据，不自行推断。切换当前 RF 协议不取消浏览器身份和互联网内容管理能力。

输入错误就地提示并保留原始输入。保存入口显示修改数；点击后给出分类汇总和逐字段前后差异，秘密仅显示“已修改”等状态，同时说明已核实的重启或生效要求。错误摘要能跳转到对应控件。

编辑、搜索、折叠和切换语言均在浏览器本地完成，不逐按键请求设备。设备只承担已有配置快照、验证、提交和必要的身份操作；交互元数据优先放在网页，避免为表单增加设备常驻 RAM。

断线、换设备和配置版本冲突时保留草稿并明确状态，重新连接后先核对身份与版本。保存成功必须以设备确认及必要读回为依据；不能把串口发送完成当作持久化成功。

## 验收与现状

已有九分类、跨分类搜索、修改过滤、结构化集合与模块、枚举及掩码控件、隐藏秘密、保存差异确认和 11 语言支持。以下仍需逐项核对，不能认定全部完成：

1. 每一个持久化设置都有适当分类、控件、帮助、范围、能力和生效说明；包括独立存储与动态配置。
2. 大量字段下完成“找到设置—理解—修改—纠错—保存”全过程，检查滚动距离与搜索定位。
3. 分类修改数及错误数、错误过滤和跳转是否完整；不能只有底层校验。
4. 所有依赖与板型能力经过事实核对；旧值、未知字段、未知掩码位得到保留。
5. 11 语言、窄屏、键盘操作及较长文案不破坏布局、不丢输入。
6. 实机断线恢复、版本冲突、持久化失败和重启后读回经过验证。
