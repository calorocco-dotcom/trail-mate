## 资源预算与优化顺序

资源验收同时记录常驻 RAM、单次操作堆峰值、任务栈高水位和并发峰值。任何一个数字都不能替代其他数字；其他目标的编译报告不能代替 RAM 紧张设备的测量。

| 项目 | 当前设计或实测 | 验收约束 |
| --- | --- | --- |
| 管理命令队列 | 复用现有队列；本机 `sizeof(PendingCommand)` 为 528 字节，关联序号使用原对齐空隙 | 不增加队列深度，不另建管理负载队列；目标 ABI 仍须确认 |
| 响应编码 | 直接写入本来就需分配的 TX 帧，去掉临时 vector 和整帧复制 | 逐长度 wire 等价；所有失败路径释放所有权 |
| 命令入队 | 去掉一个含 512 字节负载的自动局部副本 | 不据此直接缩小 FreeRTOS 任务栈 |
| 配置上传 | 单个活跃对象；320 字节块；复用命令 payload；111 字节状态日志存 SD | 不保存整文件、第二份 AppConfig 或常驻上传 arena |
| 配置提交 | 当前实现新增一个 uint32 重启时间，4 字节常驻状态 | 此数字不是整个功能的 RAM 增量；检查全部新增 `.bss/.data` |
| KML/地图/行政区查询 | 浏览器解析、编辑、索引和绘制；设备负责有界存储及协议操作 | 设备不建立 DOM、全轨迹点数组或行政区内存数据库 |
| 身份操作 | 复用设备现有 Reticulum 身份及签名路径 | 不复制私钥、不增加另一套身份运行时；签名上下文限定业务域 |

优化顺序：先减少重复复制和临时分配，再核对 decoder、CDC 与 TX 缓冲的生命周期；随后依据实际队列占用和拥塞测试决定是否减小容量。共享缓冲必须有明确的独占期与背压，不能为省 RAM 引入数据覆盖。禁止先减栈、减队列后依赖偶然通过的正常流量测试。

验收需要同目标、同编译选项的基线与功能版本对比，运行连续读取、最大配置上传、慢电脑、断线、满队列、同时 Reticulum 收发及掉电恢复场景。没有真机数据时只报告源码预算与编译结果，不声称“零 RAM 增量”或“已优化到最低”。

## 强约束（用户补充，2026-10-10）

设备 RAM 非常紧张。三项功能必须优先使用浏览器资源，尽量复用现有固件资源并优化 HostLink；不得以实现方便为由新增整文件缓存、整配置副本或任务栈。

- 新增能力默认不增加常驻大缓冲、队列深度或任务。新资源须写明增量字节、生命周期、所有者和复用来源。
- 文件、KML、附件和哈希按流处理；浏览器承担地图、XML 内容树、编辑和预览。设备只保留有界校验、必要签名状态和存储操作。
- 事务候选、出站任务与文件临时对象优先落现有 SD 存储，不为网页功能复制完整 AppConfig 或发布 runtime。
- 协议能力必须返回设备实际预算，浏览器按背压发送。04 的文件块预算只是提案，设备不需要持有整块；接收窗口需以现有缓冲容量确定。
- 无 PSRAM 设备不能自动使用内部 RAM 替代大对象分配。资源不足明确拒绝，不能靠无限等待掩盖失败。
- 不盲目缩小现有任务栈；必须通过最坏路径的真机高水位测量验证。不能把避免栈分配等同于节省总 RAM。

## HostLink 初步审计

当前命令队列深度 12，每项带 512 字节 payload，仅负载合计 6144 字节；TX 队列深度 12，持有动态分配帧指针；任务栈配置 6 KiB。CDC RX 配置 2048 字节，decoder 另有 vector 存储。上述为源码配置，实际总占用还包括结构体对齐、FreeRTOS 队列开销、allocator 开销和并发峰值，尚无真机测量。

下一步需追踪队列吞吐和拥有者、暂停/停止并发、CDC 重复缓冲以及动态 frame/payload 的重叠生命周期，再决定共享 arena 或队列减容策略。新增管理协议不能另外再建一套 12 深度大命令队列。

## 已实现的具体进展

1. `site/device/src/hostlink.js`：浏览器 HostLink v1 编解码、CRC、增量同步、握手、请求关联、超时与断线清理。没有设备作者登录假实现，HELLO 型号与 firmware 不被当成密码学身份。
2. `encode_frame_into`：新 caller-owned 编码入口，不增加常驻 RAM。
3. HostLink 事件入队直接编码到原本就需要分配的队列帧，去掉额外 vector 和整帧复制。最大帧 522 字节，节省单次路径上的额外帧存储（精确 heap 节省待真机测量），队列容量和 wire 不变。
4. `enqueue_pending_command` 去掉额外栈副本，直接使用 FreeRTOS 同步复制语义。减少一个带 512 字节负载的栈对象，不声称整个任务栈已可缩减。
