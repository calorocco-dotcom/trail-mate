# 原始 KML 流式匹配与偏离判定

更新：2026-10-13。接续35的有界展示投影，本批把导航偏离判定从展示采样改为原始几何匹配，不修改 USB/RNS 操作、作者身份或 RF 设置。

## 匹配与来源

地图展示仍保留最多96点。匹配读取当前路线的全部原始 LineString/gx:Track 坐标，每种几何仅保留前一个点和标量统计，不建立第二份轨迹列表。选择规则与展示一致：存在可用 gx 点时使用 gx，否则使用普通线段；缺失 gx 样本和几何边界断开，不产生跨段连接。

距离按6371000米球面、短大圆弧定义计算，处理跨日期变更线；严格对跖点不能唯一确定弧，所选几何遇到它则不产生有效匹配。无须地形模型的平面投影近似已经从实际偏离更新路径移除，旧采样距离辅助函数暂留以维持既有原生回归。

匹配累积到路线上的投影位置、沿路线的里程、总长和终点距离。回环/交叉导致不同里程位置同时最近时标记歧义，不把第一次空间接近等同于走完路线。当前用户界面只使用距离边界判断偏离；这些里程标量还不是导航进度/到达界面的完成证据。

路线加载两遍投影后输出两类几何的坐标计数与指纹。每次匹配只有完整 XML EOF、日期/配对/几何校验、指纹一致和文件关闭成功后才提交结果；截断即使已输出坐标也不能提交。指纹仅检测加载后的几何变化，不替代安装包原作者签名和文件SHA。改变其它未选用几何也会使指纹核对失败。

## 调度与内存

接入既有100ms地图定时器，不新增线程/队列。每次poll最多64个256字节块，并在块之间检查4ms经过时间；单个SD读取的阻塞时间不由此保证。定位未改变时5秒内复用有效结果；普通重试间隔至少1秒。大文件的真实完成延迟、SD阻塞与触摸流畅度尚未实测，不能把原生速度当作Wio性能。

活动路线的所有者上限384字节，动态申请；新增常驻符号是一个4字节指针，整体链接静态RAM净增8字节。XML工作区上限12544字节，只在读取期间存在，EOF/失败/取消即释放。Wio的所有者和工作区都在PSRAM，有PSRAM时申请失败不回退内部堆；没有PSRAM的平台沿用原读取器的内部堆策略。新路线替换释放旧所有者，地图关闭、临时选点/目标模式、失去定位或SD不可用取消读取并关闭文件。

## 读取期间移动

匹配固定本次开始时的定位，完整读取后得到该定位到路线的距离。使用开始定位到当前定位的球面距离作为误差界：当前距离在 `max(0,原距离-位移)` 和 `原距离+位移` 之间。

只有下界超过10米才进入偏离状态；只有上界不超过7米才解除既有偏离状态。区间跨越阈值时不假造明确结论。提示中的距离使用保守下界；下界不足7米时不显示“偏离0米”一类矛盾提示。结果超过15秒、输入失效或文件读取/校验失败则不提供有效距离，也不会宣称已经在线路上。此界限针对报告的GPS坐标，不等于消除GPS传感器本身的误差。

## 验证

新增原生测试使用生产匹配类、XML解析器和实际地图推进/偏离更新函数。覆盖被96点展示跳过的弯折、球面距离/里程、跨日期变更线、不经过零经度的反向查询、回环歧义、断段、空gx、gx优先及未选线段的对跖点。还验证分批/时间预算、EOF前没有结果、源变化/截断、读/关闭失败、两阶段内存不足、离开地图取消、失去定位，以及移动区间不错误解除旧警报。模拟FS/堆下所有句柄及工作区释放，没有内部caps申请。

8项相关CTest、9项浏览器完整包准备/安装及上传互操作回归通过；ESP栈、轨迹流式读取与差异检查通过。最终格式化后实际地图函数片段重新提取、重编译并再次通过新增匹配测试。

Wio SDK构建PID33320明确退出0、SUCCESS188.18秒，stderr为空。静态RAM95,556字节（上一候选95,548，净增8），Flash4,785,517字节，bin4,785,936字节，SHA256 `d3200bc3e432c07504b70dfa3fd0b231060cfb8bc9e787b9d13addc6bd1413d6`。实际镜像53项能力含98/99/100/101及应用分区预算核验通过；ELF确认4字节活动路线指针、实际匹配/开始/取消/释放入口。没有刷写，已刷镜像仍为b733480e…，用户验收的87K/297K读数没有新的测量替代。

## 剩余范围

本批覆盖“实际偏离判断仍依赖96个采样点”，不覆盖导航进度/到达交互、设备逐点时间回放、GPX/CSV完整语义、GPS误差处理和大文件实机延迟。真实SD、显示/触摸、掉电/峰值、网页完整附件管理/多语言任务恢复/导出、公网目录和身份恢复实测继续保留在16；没有刷写或新的运行RAM读数。
