# 本机身份备份与恢复实施

## 已确认的存储事实

Wio Arduino 的 LxmfIdentity 保存 enc_priv 32 字节与 sig_priv 64 字节展开签名私钥，公钥为 enc_pub 32 + sig_pub 32，共 64 字节。设备身份对象 200 字节约束已有静态检查，author_generation 使用既有对象空间。不能把这 96 字节私钥材料直接当作常见的 64 字节 Reticulum 种子私钥，也不能从展开后的签名密钥假定可恢复原种子。身份恢复必须推进代次，即使恢复相同公钥。

事实来源：lxmf_identity.h/cpp、identity_generation_store.h。设备 MAC/node ID 与 Reticulum 作者身份不是同一材料；配置备份和 rt.group 群组引用也不是本机身份备份。

## 已实现的备份载荷契约

浏览器 encode/decodeIdentityBackupPayload 使用有界 CMP1：`[1,"trailmate.identity.backup.v1",format,public64,private,identity16,delivery16,generation]`，载荷不超过 320 字节。format=0 为 Arduino 展开表示（96 字节），format=1 为 Reticulum 种子表示（64 字节）；各格式固定宽度且拒绝缺失密钥部分。签名域为 `TrailMate.Identity.Backup.v1\0`，签名覆盖完整载荷，包含私钥表示。

verifyIdentityBackupPayload 要求调用方提供当前已验证设备公钥及 generation；核对载荷公钥/代次、从公钥导出的身份哈希/LXMF 投递地址及作者签名。返回独立字节副本，不借用串口响应。验签证明载荷由当前作者认证，不证明私钥与公钥的数学一致性；实际导出必须从身份对象读取真实材料，恢复必须由平台密码学实现进一步验证密钥配对。

2 项 Node 测试通过，使用真实身份签名认证合成私钥载荷，覆盖两个宽度、返回副本、错误长度/地址/代次/签名拒绝。没有真实私钥读取、设备导出、USB 交换、加密备份文件、恢复写入或固件编译。
