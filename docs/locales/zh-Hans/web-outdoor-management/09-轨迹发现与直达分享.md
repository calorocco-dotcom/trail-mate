# 轨迹发现、稳定 ID 直达与剪贴板分享

本文件补全 08 的公开发现流程：地图探索、行政区层级查询、稳定 ID/链接直达是三个并列入口。分享操作贯穿我的资料库、公开摘要和详情。

## 1. 标识不能混用

04 的 object_id 是共享轨迹条目的稳定标识，名称、KML 内容和版本变化不改变它。manifest_hash 指定精确发布版本；file hash 指定 KML 精确文件。KML XML 的 id 属性是文件内元素标识，不能假设其跨文件或跨作者全局唯一。

用户看到的“轨迹 ID”使用完整 object_id 的可复制文本编码。提案：`tmtrk1_<64个小写十六进制字符>`。前缀用于类型识别，不是密码或权限令牌。显示可以缩略，复制必须完整；输入校验前缀、长度和字符。是否增加 checksum/更紧凑编码在协议冻结时决定，当前不承诺短码无碰撞。

文件名、标题、KML 内部 id、短指纹都不能冒充共享条目 ID。原始未发布文件只有本地标识和文件 hash，界面标注“尚未公开”，不生成会被误解为已经可用的公开链接。

## 2. 直接查询

公开页面顶部固定搜索框：“搜索名称、粘贴轨迹 ID 或分享链接”。解析到有效轨迹 ID 时进入精确查询；普通文字进入关键词查询。格式错误就地提示，不静默当成关键词。另有“通过 ID 打开”按钮供显式粘贴。

网络新增 LOOKUP_OBJECT：`[object_id, manifest_hash|null]`，响应含签名 manifest 或版本候选、目录当前性、可用文件/附件来源和明确状态。与 GET_MANIFEST 区分：后者已知道精确版本 hash，LOOKUP 用于只知道稳定 ID 的首次定位。

无版本参数时查询已连接的多个目录，对签名版本和父链做校验；合法后继版本可选为当前候选，分叉则呈现版本选择与来源，不宣称全网唯一最新。指定 manifest_hash 时只打开该版本，并标明是否历史版本，不能偷偷替换成新版本。

结果状态包括 Found、Archived、Conflict、NotFoundAtSource、TemporarilyUnavailable、Unsupported。一个目录没有记录不等于全网不存在。全部已连接来源未找到时说明查询范围，并提供重试/添加来源，不创建空轨迹。

## 3. 分享格式与剪贴板交互

采用 Pages 相对部署基址生成链接，例如：

`https://<站点>/<项目前缀>/tracks/?id=tmtrk1_<object_id>`

固定版本链接增加 `&rev=<manifest_hash>`。不把 USB 端口、会话 ID、私钥或个人本地路径放进 URL。初始来源可选，但只作为不可信发现提示；验证仍依赖作者签名与文件哈希，不自动连接任意来源。

详情标题旁显示“轨迹 ID · tmtrk1_…”，配复制按钮。分享按钮打开面板：复制轨迹 ID、复制跟随更新的链接、复制当前版本链接、二维码（可选）。说明“跟随更新链接可能显示后续版本；当前版本链接固定内容”。

列表每行、地图摘要和本人共享详情均可分享。点击复制后显示“已复制”，支持键盘操作；剪贴板失败时展示选中的完整文本供手动复制，不能仍提示成功。操作由用户点击触发，HTTPS 下使用 Clipboard API；可用时调用系统分享，否则保留复制路径。

收到链接无需网页登录或连接设备即可查看公开条目；维护权限仍由设备作者身份决定。共享 ID 可在其他兼容客户端使用，不把某个网页域名作为条目身份。

归档记录仍可按 ID 查询，显示归档状态和历史；作者归档不销毁 ID。隐私方面稳定 ID 可关联公开版本，公开前说明这种持续关联。

## 4. 地图探索

拖动/缩放停稳后，可按当前视野自动查询。提供“随地图更新”开关和“搜索此区域”手动按钮；仅在开关打开时自动搜索。先显示原结果并标记更新中，成功后统一替换，失败保留结果与重试。

合并快速连续手势，旧查询 generation 不覆盖新结果；按接口预算限速、取消未发送请求。远景聚合，近景展示有界简化轨迹。QUERY 响应需要聚合/预览能力与预算，预览为目录声明，详情再验证精确 KML。地图选择与列表双向联动，选中详情不会因后台刷新突然关闭。

## 5. 行政区层级

按用户 2026-10-14 的收尾要求，面向全球，采用简洁的国家/地区 → 一级行政区选择；省、州等名称由区域数据决定。不把中国市县完整目录或更深行政层级作为本次开发内容。任一级均可查询，面包屑可返回国家/地区。行政区标识带命名空间与数据版本，不用名称作为唯一主键。

选择区域显示边界并定位，按真实区域相交查询；bbox 只作预筛选。轨迹跨区允许进入多个结果，摘要标注经过区域。QUERY 增加 region_id/boundary_version/spatial_relation，目录能力声明支持层级和边界版本；不支持时明确提示，不能伪装为精确行政区结果。

行政区锁定与地图视野是互斥查询范围模式。锁定时拖动地图只改变视角，范围标签仍显示选定区域；用户点击“改为当前视野”切换。直接 ID 查询忽略现有空间过滤，命中后定位该轨迹，保留返回原查询的入口。

## 6. 三个发现入口的交互安排

顶部固定统一搜索框与“通过 ID 打开”；侧栏范围模式是地图/行政区。地图工具包含随地图更新、搜索此区域；行政区模式出现层级选择和面包屑。摘要含 ID 复制和详情；详情含完整分享面板。

输入分享链接直接打开详情，不要求先定位行政区、拖动地图或逐页搜索。浏览器刷新、前进后退和 URL 深链接恢复 ID/版本；查询条件编码与身份会话分开，不在 URL 泄露设备秘密。

## 7. 验收

完整 ID、大小写/前缀错误、复制完整而非缩略 ID、Clipboard 拒绝回退、Pages 子路径链接、固定版本/跟随更新、归档直达、不同目录分歧、首次无网络后重试、未发布条目禁止假公开链接。

地图快速拖动迟到结果不替换、聚合放大与列表联动、跨日期线；行政区逐级/上级查询、同名异区、边界版本不兼容、跨区轨迹；通过 ID 忽略空间筛选并能返回原查询。
