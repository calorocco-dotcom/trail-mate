# KML 导航与预览的有界采样、分段和高度

更新日期：2026-10-13。本批接续完整包安装和离线图片显示，修正设备导航及轨迹预览的 KML 读取；不改变设备作为网页身份的规则，也不依赖当前 RF 协议。

## 已实现的处理

导航和预览共用两遍流式读取。第一遍完整解析、核对结构并统计可用的 LineString 和 gx:Track 坐标；有可用 gx:Track 时优先选用它，否则使用 LineString。第二遍遍历所选几何的所有原始点，累计真实距离和高度统计，只保留最多 96 个展示点及 96 个剖面样本。第一、末点保留，输出样本之间的距离使用原始点累计值，不改写源 KML。

源解析工作区沿用既有短期 PSRAM；点和剖面改用固定容量缓冲。有 PSRAM 时申请失败不退回内部 RAM，返回失败并清空结果。没有完整坐标列表、第二份完整预览列表或新的后台线程。投影对象只含标量与单个前点，编译期大小上限 256 字节。

两个读取阶段使用几何指纹核对所选坐标及高度模式，发现变化时丢弃结果；这是防止两遍投影不一致的检查，不能替代安装包的原作者签名、文件摘要或来源核验。

每个 LineString、gx:Track 及缺失 gx:coord 保持独立边界。采样跳过边界点时，也把断段标志传给下一个保留点。距离不跨断段累计，升降不跨断段或缺失海拔累计。Point 和 Polygon 的图片定位保留，但不当作步行轨迹；只有这类要素的文件可以预览图片，导航加载则明确返回没有可走轨迹。

默认贴地、clampToGround、relativeToGround、clampToSeaFloor 和 relativeToSeaFloor 不提供绝对海拔剖面；明确 absolute 才统计海拔。高度模式在 coordinates 前后均可读取，未知或重复模式拒绝。没有地形数据时不虚构相对高度到绝对海拔的换算。

gx:Track 的 when 使用共享日期时间校验，包括闰日和时区语法；提供 when 时数量须与 coord 相等，空 coord 也占一个样本位置并形成断段。缺失时间不生成假 UTC。签名几何读取也允许明确的空 gx:coord，并要求非空 gx 坐标有三个分量。原签名域和记录格式不变。

## 地图绘制

导航把既有覆盖层快照中的路线点标为有序路径样本，断段标志置于原结构的填充空间；原生布局断言确认不增加快照大小。绘制回调借用快照直接绘线，不为每个路径点创建 LVGL 对象，也不新增顶点列表。投影失败、不可见点或样式改变不跨接。

路径回调在没有普通标记绑定时也注册。覆盖层更新显式 invalidate，因此纯路径变化和清空都能重绘；普通图片、队友和其它标记继续走原标记处理。

## 保留的交付缺口

96 点用于受限设备的展示和近似匹配。目前偏离判断仍基于采样段，不能宣称复杂曲线的精确匹配、导航进度或到达判断已经完成。gx 时间校验不等于逐点时间回放；设备不额外保存完整时间数组。GPX/CSV 的存储也改为有界，但其旧读取语义尚未获得本批 KML 相同的完整验证。

真实 SD、地图显示、触摸、安装后导航、掉电恢复和运行峰值尚待实机验收。网页完整附件管理、多语言完整包流程、跨刷新任务恢复、完整包导出和真实网络目录联调仍保留在 [交付缺口核对](16-交付缺口核对.md)，不以本批测试通过替代。
