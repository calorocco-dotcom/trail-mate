## 当前实现与新增设计的边界

- HostLink 已有 USB CDC 二进制帧、512 字节负载上限、握手、部分配置读写和应用数据收发。现有命令不是完整配置 API。
- Reticulum 网络配置已通过 `/trailmate/config.tms` 保存；不能另造网页专用配置文件成为第二事实来源。
- Geocaching 已有设备签名、发布任务与恢复机制；网页已有 Reticulum/LXMF 查询和验签，但使用临时访客身份。
- Tracker 当前记录 GPX、CSV、Binary，Route 已有 KML 路线存储。共享 KML 需要转换与验证，不假设记录器已经直接产出 KML。
- 新串口管理服务、完整配置 schema、网页作者命令和轨迹共享网络协议均为本草案提出的新增能力。文中名称、编号和预算不是当前固件已支持的接口。

## 架构决定

浏览器负责录入、地图、预览和本地编辑；设备负责配置事实来源、作者身份、版本提交及持久化任务；Reticulum 承担网络发现与传输，业务目录提供可验证的索引与保存回执。

Geocaching 继续使用现有协议，不为网页另建发布协议。轨迹使用独立、明确版本化的应用协议，复用身份和传输基础，不占用 Geocaching 既有操作编号。

网页自身由 GitHub Pages 静态托管，发布户外内容不要求重新部署网页。去中心化意味着可以配置、发现和使用多个目录/文件节点，并验证内容，而不是承诺任何单节点永久在线。
