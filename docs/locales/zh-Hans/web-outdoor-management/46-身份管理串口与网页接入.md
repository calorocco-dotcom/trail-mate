# 身份管理串口与网页接入

2026-10-13。本批接通 45 的 RF 身份存储与浏览器维护；设备的 Reticulum 作者身份仍是网页账号，当前 RF 协议不限制配置管理、作者证明或电脑网络发布。本文覆盖 45 中“尚未接入 USB／网页”的状态，不把电脑测试当作实机验收。

## 实际串口契约

复用 Hostlink 512 字节管理负载、现有会话和请求关联；新增 7／8／9，能力列表增至 56 项。没有新增队列、任务或完整身份常驻缓存。

| 操作 | 请求 body | 成功 body |
|---|---|---|
| 7，RF 身份信息 | `[当前作者代次, kind]` | `[kind, 存在0或1, RF本地代次, 公钥32或nil]` |
| 8，RF 身份导出 | `[当前作者代次, kind, 明确同意true]` | `[签名载荷bin, 作者签名64]` |
| 9，RF 身份恢复 | `[当前作者代次, 当前作者公钥64, 签名载荷bin, 签名64, 预期RF代次, 预期RF公钥32或nil, 明确同意true]` | `[已提交0或结果不确定1, kind, 下一RF代次, 恢复公钥32]` |

kind=1 为 MeshCore 原生 expanded Ed25519 私钥64／公钥32；kind=2 为 Meshtastic 已夹紧 X25519 标量32／公钥32。不能把两者或 Reticulum seed 格式互换。未生成的 RF 身份可以只读查询，查询不生成密钥；未生成时导出不可用。

签名载荷是固定十字段 CMP1：

```
[1, "trailmate.radio.identity.backup.v1", kind,
 RF公钥32, RF原生私钥64或32, 导出设备Reticulum组合公钥64,
 导出作者代次, 导出RF代次, 导出USB会话16, 导出请求16]
```

签名输入为 `TrailMate.Radio.Identity.Backup.v1`、一个 NUL 字节、精确载荷字节。会话／请求来自实际管理信封，浏览器要求与本次导出一致；合法旧导出不能冒充新请求回复。离线恢复则验证原签名与密钥，不要求历史导出会话仍在线。

管理信封此前拒绝 MessagePack 布尔值，造成带明确同意的完整请求无法通过分派。现在管理编解码明确接受 canonical `false/true`；Geocaching 既有编解码默认仍拒绝布尔，不隐式更改其线上子集。测试覆盖完整信封及请求／响应复用同一命令缓冲。

## 身份与存储边界

MeshAdapterRouter 读取已存 Reticulum 身份并加锁，不依赖活动 RF 后端。RF 恢复核对当前作者公钥／代次、原作者签名、载荷与解析视图一致性、实际公私钥对应、目标 RF 公钥／代次，然后提交 112 字节单记录。RF 代次变化不会改变 Reticulum 作者代次。

恢复复用既有身份维护准入与工作区，阻止配置、上传、内容签名、轨迹快照或路线安装进行中替换身份。RF 单记录写入另有一个字节的原子状态；恢复提交确定或不确定后均阻止后续 native RF 写入，直到应用重启。网页只发送一次恢复请求，回复丢失不能自动重复写入；重连后重新证明同一网页作者，再查实际 RF 公钥及代次。

恢复请求工作区上限保持 512 字节，ESP 上本轮 RF 结构约 428 字节，按需在 PSRAM 申请并清理；单记录工作区为 144 字节。不存在可用 PSRAM 的板型仅在单记录层允许有界内部申请；USB 恢复准入仍沿现有 PSRAM 要求，不据此宣称所有板型都可恢复。没有新增完整密钥对象的栈局部变量。

## 现有设备页面中的交互

入口在设备管理第一页“设备与身份”，位于作者身份恢复与加密作者身份导出之间，沿用现有 Pages 导航、颜色、按钮和对话框。

1. 密钥类型选择 MeshCore 或 Meshtastic，与当前无线协议无关；读取后显示公开公钥和 RF 代次。
2. 导出要求口令／确认口令和明确同意，先校验口令，再读取私密响应；立即加密为独立 `.tmrf` 文件，只将密文交给下载入口。
3. 恢复先选文件和解密，再显示备份公钥、当前公钥、代次变化和备份来源作者；审阅阶段移除口令输入。明确同意后才允许写入。
4. 离线可审阅文件；写入需连接支持的设备。断开、切换设备、取消或失败会清理私密工作数据。
5. 提交后保留公开核验目标，重连读取后才显示验证成功；同一页面中断开连接不会丢失该目标。当前核验目标未跨整页刷新持久保存，不能宣称刷新后自动恢复核验。

加密文件使用 TMRFENC1／40 字节头、PBKDF2-SHA256 600000 次、AES-256-GCM／128 位标签；头部作为 AAD，随机 salt16／nonce12，文件最多 504 字节。与 Reticulum `.tmid` 分开，避免错误格式被当成另一种身份导入。解密材料只存临时 ref／工作区，不放入 React 状态、URL 或浏览器持久存储；JavaScript 引擎内部副本不保证可控擦除。
