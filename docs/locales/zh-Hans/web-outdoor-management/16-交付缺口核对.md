## 用户澄清后的职责边界（2026-10-12，覆盖此前设备网络发布假设）

设备是独立账号凭据，当前 RF 协议与 Web 使用无关。浏览器通过电脑网络接入 Reticulum；现有 Geocaching 浏览 worker 的 WebSocket/IP 连接应扩展为维护功能的网络入口。USB 承担配置管理、作者证明及设备身份授权的内容签名，不以设备 RF 后端为网页网络传输的先决条件。

目前网页维护流程仍调用设备目录发现/发布任务，尚未满足这一边界，必须迁移。目录传输身份与内容作者身份的绑定须按真实目录协议检查，不能直接假定浏览器临时传输身份可代替作者。不得为了网络发布要求用户切换设备无线协议。实机作者证明已通过，网络维护流程仍未完成。
