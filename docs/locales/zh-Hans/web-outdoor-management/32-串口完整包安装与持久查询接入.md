# 串口完整包安装与持久查询接入

更新：2026-10-13。本批将 [31](31-共享包原作者验证与路线提交.md) 的安装事务接入管理串口、现有调度器和浏览器 API，新增不依赖上传暂存的持久查询。本地实际 CMP/C++/签名/存储联调通过；多语言安装面板、离线附件显示/导航及实机仍待完成。

## 新操作与原有请求

安装操作 `TrackPackageInstall = 100`：

```text
[operation_id:bin16,kml_upload_id:bin16,signed_manifest_upload_id:bin16,
 current_device_generation:u32,nil,attachment_mapping_upload_id:bin16|nil,
 expected_object_id:bin32,expected_revision_sha:bin32]
```

原作者签名容器用 kind11（最多4166B）上传，不能把 unsigned kind4 当作共享作者签名。请求中的 nil 保留原准备请求父版本位置，但安装不能预留/更改自己的发布版本，因此拒绝非 nil。

持久查询 `TrackPackageInstallStatus = 101`：

```text
[operation_id:bin16,current_device_generation:u32,
 expected_object_id:bin32,expected_revision_sha:bin32]
```

两操作返回相同形状：

```text
[operation_id,state:u8,object_id:bin32|nil,revision_sha:bin32|nil,
 installed_route_path:str|nil]
```

state0 未完成，后三项全 nil；state1 已安装且核验通过；101 的 state2 表示目标路线缺失。100 不返回缺失作为成功，也不返回/生成新的作者签名。错误签名/字段/文件损坏仍返回对应错误，不能伪装为已安装。

对象/版本和路线路径均精确匹配；路线为 `/routes/p-<完整版本SHA>.kml`，不接受网页任意路径。原82/96继续五字段，99继续六字段，新100八字段不会混入旧入口；101独立四字段解码。串口仍512B frame/320B块。能力列表新增100/101（共53项），旧设备不能被原Transfer/99能力推断为支持安装。

## 单调度槽与互斥

原 `prepare_runtime::work` 指针改为小型作业接口，仍只有一个指针，没有新增全局安装队列/槽。原 TrackPrepareWork 与 PackageInstallWork/PackageQueryWork 均在短期 PSRAM，原准备缓存 <=320B 约束保持。

安装期间持有已有 route_storage_lease，UI 删除/图片工作不能与安装磁盘事务交叉；断线、过期、错误和作业销毁释放，完成后也立即释放大作业与租约。相同请求 ID 和冻结绑定用于轮询，另一个会话/对象/上传绑定不能抢占活动作业。

每步读取当前设备公钥/摘要/代次，仅用其授权本机写入或查询；原作者签名保持。软件配置重启、配置事务、快照、发布和活动目标路线通过既有策略协调；安装不覆盖正在使用的路线。后台安装/查询推进加入既有存储维护 gate，原签名准备的推进路径保持。

完成结果重新核对当前设备身份后才可返回；失去当前身份时不沿用旧 ready。作业接收轮询后续期30秒，失去连接/超时释放，磁盘上的命名恢复依据保持。

## 安装流程

浏览器冻结原签名、KML、附件、ID和目标对象/版本；先验签、核对 KML/索引/提供资源及容量，再读回当前本地设备身份，然后串行上传并调用100。错误本地内容在上传前拒绝。没有设备内容签名调用，也没有 RF/设备目录操作。

设备按31的实际校验 → 公共缓存 → 绑定记录 → 最后 `.kml` 发布执行。大工作区完成即释放，成功只保留 <=288B 的短期安装结果。重复安装使用同一原签名和命名文件，核对既有数据与前缀后恢复，不写自己的发布头。

100 的重复成功是原操作结果，不能代替当前磁盘状态；网页恢复/核对应使用101。

## 持久查询的证明范围

查询不使用上传 ID，不需要暂存日志或原本地创建代次。当前连接仍需要合法设备身份，公开包的原作者可以是其他设备。

`StoredPackageInputOwner` 先读取154B本地绑定记录，CRC仅检测损坏/定位；再读取并验证公共缓存中的原始签名、完整对象/版本、KML及索引描述符。索引实际 SHA/结构/长度、所声明已保存的资源实际 SHA/大小，以及**实际 `/routes` KML 的 SHA/几何**继续分块核对。

可选缺省按本地可用性位图保留，必需缺失不能通过。声称已保存的可选资源损坏/缺失也不能通过。存储路径从版本及资源 SHA 推导，不能由引用 URL 指定。查询每项返回前关闭文件句柄，不改写磁盘。

一次查询成功后，下一笔查询（即使同一查询 ID）仍重新读取磁盘；旧短期成功结果会先退休。已安装后资源损坏不会被旧 success 掩盖。实际路线不存在时返回缺失，路线存在而绑定/签名/资源不完整时返回错误；不根据文件存在或 CRC 单独宣布成功。

查询源 owner <=24576B 短期 PSRAM，完成只保留 <=224B 结果，SD Impl 另计；资源路径工作槽在查询模板中为160B，普通上传校验仍默认64B。无新增常驻目录表或任务栈大数组。CRC、签名及文件证明不等于图片格式可解码、导航语义或当前网络头。
