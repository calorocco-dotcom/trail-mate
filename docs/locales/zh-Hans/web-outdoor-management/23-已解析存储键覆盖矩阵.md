# 已解析存储键覆盖矩阵

2026-10-12。按 [22-持久化入口清单](22-持久化入口清单.md) 中已解析的 40 个 namespace/key 组合逐项核对。这里的“源码有投影”只表示存在对应导出和应用代码，不等于每个字段都已实机保存、重启和生效验收。当前 61 个动态调用、直接 Preferences/NVS 接口、其他平台和第三方库仍须继续追踪，不宣告全部配置已覆盖。调用数因基础标量写入改用读回检查包装器而变化，见 [24](24-动态存储入口覆盖核对.md) 最新说明。

源码依据：

- [settings extension](../../../../platform/esp/arduino_common/src/app_config_tms_settings_extension.cpp)：`writeRecords` 导出、`finishRead` 完整校验与应用；包括独立展示偏好、Wi-Fi profiles、条件 cellular/C6 与 Reticulum 网络配置。
- [C6 extension](../../../../modules/core_sys/include/app/tms_c6_config_extension.h)：14 个字段的宏写入、消费及完整 presence 校验。NVS 长键别名仍按 [17](17-独立持久化设置覆盖.md) 的共享映射处理。
- [Wi-Fi runtime](../../../../platform/esp/common/include/platform/esp/common/wifi_runtime_impl.h)：保存 profile 集合与旧首项兼容值；不能把兼容值当成另一个独立用户设置。
- [资源包 locale 迁移](../../../../modules/ui_shared/src/ui/i18n/resource_pack_registry.cpp)：旧 display_language 向 display_locale 迁移，随后删除旧键。
- [调试日志](../../../../platform/esp/arduino_common/src/debug/sd_debug_log.cpp)：core_seq 用于生成崩溃转储文件名，是内部记录。

## 仍须完成的全集核对

动态入口包括蜂窝文本键、Wi-Fi profile 模板、通用设置页适配器、C6 宏与严格文本读取、聊天 blob 版本/CRC 和身份等包装器。必须追到调用实参，再区分普通配置、账号密钥、用户数据、迁移输入和内部运行记录。分类不能成为跳过相应管理功能的理由；身份继续通过专用证明/备份/恢复协议维护。

AppConfig 的传统 Preferences 缓存必须逐域对照核心 TMS；不能只扫描 `settings_store` 或只验证 231 个已知 TMS 字段族。范围/默认值/板型能力/生效方式与全部 UI 状态仍需整合进最终覆盖矩阵，并通过恰当的设备验收证明。
