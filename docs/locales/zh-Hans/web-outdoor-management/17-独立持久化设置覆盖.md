## 已确认缺口：P4/C6 配置

`platform/esp/idf_common/src/c6_companion_runtime.cpp` 的 `load_espnow_config_from_p4_settings` 与 `load_wifi_config_from_p4_settings` 从独立 NVS namespace `c6_companion` 读取以下 14 个键。当前三个 TMS codec/extension 未包含这些键；已有 `wifi.enabled`/profile 表来自共享 Wi-Fi 配置，不能替代 C6 的 AP、STA 和 ESP-NOW 独立设置。此缺口不影响 Wio L2，但阻止宣告全部支持板型的全部配置完成。

| 存储键 | 含义 | 当前设备读取约束 |
|---|---|---|
| espnow_enabled | ESP-NOW 开关 | bool |
| espnow_team_discovery | 团队发现开关 | bool |
| espnow_channel | ESP-NOW 信道 | 0–14；0 的语义需按协议确认 |
| espnow_beacon_interval_ms | 发现广播间隔 | 1–60000 ms |
| wifi_enabled | C6 Wi-Fi 总开关 | bool；共享 Wi-Fi 已启用且有 SSID 时会强制启用 STA |
| wifi_sta_enabled | STA 开关 | bool |
| wifi_ap_enabled | AP 开关 | bool |
| wifi_persist_credentials | C6 凭据保留策略 | bool |
| wifi_sta_ssid | STA SSID | 固定数组容量与协议校验待核对；缺键回退共享 SSID |
| wifi_sta_password | STA 密码 | 固定数组容量与协议校验待核对；缺键回退共享密码 |
| wifi_ap_ssid | AP SSID | 固定数组容量与协议校验待核对 |
| wifi_ap_password | AP 密码 | 固定数组容量与协议校验待核对 |
| wifi_sta_channel | STA 信道 | 0–14 |
| wifi_ap_channel | AP 信道 | 1–14 |

实现要求：仅在 P4/C6 有对应能力时导出/编辑；以独立字段保留 AP/STA 和 ESP-NOW 意图，提交前校验组合与信道约束；明确共享 Wi-Fi 导致的有效状态变化。密码进入现有加密备份流程。读写需复用按需工作区，不新增常驻大对象，不在 ESP 栈放完整 companion 配置。写入完成后按现有 companion 配置协调入口应用或明确提示重启，不以保存 NVS 成功代替实际 C6 状态确认。
