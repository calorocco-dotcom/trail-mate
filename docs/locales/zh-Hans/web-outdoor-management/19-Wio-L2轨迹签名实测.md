- 状态：prepared=true，published=false。

测试使用独立对象，没有覆盖用户现有轨迹；设备本地新增了测试对象与上传记录。此过程没有调用 RF 目录、RF 发布或网络发布操作。设备始终保持 Meshtastic 配置。

## 证据边界

此结果证明真实设备上的 USB 上传、本地持久化准备及签名与网页校验代码互操作，且该路径不要求当前协议为 Reticulum。测试使用串口桥和 Node 运行网页模块，没有验证浏览器 Web Serial 授权与页面完整操作。

尚未证明网络目录发布、发布回执同步、后续更新与归档、掉电恢复、运行时 RAM 峰值或所有配置实机保存。该固件也不包含构建完成后新增的“身份完全缺失时安全初始化”源码调整，不能用本次测试证明首次身份生成。

本地复现脚本：`.codex-build/hostlink-wio-l2/track-sign-probe.mjs`。再次运行会生成新的独立测试对象，避免无目的重复运行。
