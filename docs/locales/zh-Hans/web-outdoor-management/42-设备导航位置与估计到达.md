# 设备导航位置与估计到达

更新：2026-10-13。接续36的完整原始KML匹配，补充导航位置、剩余记录路径长度和估计到达的设备提示。没有新增串口命令、网络协议、任务或坐标队列。

## 位置与剩余距离

现有地图通知区在没有临时通知、偏离警报或Geocaching目标时，显示原始KML匹配的沿线路径位置百分比与剩余长度。它是最近匹配位置，不是已经行走的里程或单调累计进度；断段之间不补连接距离。没有有效定位、存储不可用、正在匹配、多解和结果不可用分别显示对应提示。

位置显示要求结果不超过5秒，读取时位置到当前定位的移动不超过3米，且保守的离线距离上界不超过7米；不对旧扫描结果推算前进位置。多解时不显示唯一百分比，不自动选择交叉或往返路径的某一分支。

## 估计到达

标量领域状态RouteNavigationState存储在既有KmlNavigationMatch所有者中。先观察过剩余长度至少20米的有效位置，才允许候选到达；仅在剩余记录长度不超过10米、保守终点距离不超过10米、唯一有效匹配下开始候选。两个独立完整扫描结果需要覆盖至少5秒，连续扫描之间超过6秒则重新开始驻留。重复渲染同一结果不累计时间。

打开路线时已经站在终点不自动报到达；闭合/往返起终点出现多解也不报到达。缺定位、切换页面/目标、源校验失败、读取/关闭/内存失败清除候选。界面称“估计到达线路终点”，不能等同于高精度地理测量或已经完整走过所有路段。GPS误差模型和分支/方向选择仍需进一步验收与设计。
