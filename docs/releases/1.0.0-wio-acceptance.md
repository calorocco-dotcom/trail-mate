## Limits of this acceptance

The full Geocaching browser harness did not finish green. After both publication
and confirmation operations succeeded, switching interface languages caused an
extra catalogue read; an assertion requiring the total USB request count to stay
fixed failed (`281` versus `280`). The subsequent independent native, proof and
device-readback checks establish the publication result, without publishing
another revision. The remaining locale/reload tail of that browser run is not
claimed as passing.

On October 16 the user explicitly confirmed that physical acceptance of the
latest navigation and menus was complete, including visual presentation, touch
interaction and actual route following. These Wio hardware acceptance items are
closed. This is user-reported physical acceptance; the image receipt above
records the earlier combined upload and does not identify subsequent builds.

This acceptance does not publish a stable tag, GitHub release or Pages deployment,
or establish a ten-target build result for later working-tree changes.

The matching image, ELF, source manifest, build/upload logs and public acceptance
receipts are retained locally under
`.codex-build/navigation/combined-device/` until release acceptance is complete.
